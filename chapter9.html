Chapter 9: Tuples and Sets

A tuple is used to store multiple values in one variable. Tuples are ordered and allow duplicate values. They are immutable, which means once created, their values cannot be changed. Tuples are written using round brackets ().

What is special about tuples?

A set is another collection type. Sets are unordered and do not allow duplicate values. They are useful when you want only unique elements. Sets are written using curly brackets {}.

What happens if you add duplicate values to a set?

Sets support operations like union, intersection, and difference. Union combines elements from two sets. Intersection gives common elements. Difference returns elements that are in one set but not in the other.

Lists and tuples both store multiple values. Lists are mutable, meaning they can be changed. Tuples are immutable and cannot be modified. Lists use square brackets [], and tuples use round brackets ().
