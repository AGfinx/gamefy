Chapter 13: File Handling

File handling allows us to work with files stored on a computer. Instead of keeping data only in memory, we can save it permanently inside a file. Python provides built-in functions to read and write files easily.

Why do we use file handling in Python?

To read a file, we open it using open() with mode "r". The read() function is used to get the content. After reading, it is important to close the file properly.

Which mode is used to read a file?

To write data into a file, we use mode "w". If the file exists, it will overwrite the old content. We use write() to insert text into the file.

What happens when we use mode "w" on an existing file?

To add data without deleting existing content, we use append mode "a". This adds new text at the end of the file. After finishing, we close the file using close().
