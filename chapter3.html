Chapter 3: Input and Output

The input() function is used to take information from the user while the program is running. Whatever the user types is stored as text by default. This allows programs to become interactive instead of showing only fixed output.

What does the input() function do?

Type conversion means changing one data type into another. Since input() stores values as text, we often convert them into integers or decimals. Functions like int() and float() help us perform mathematical calculations correctly.

Why do we use int() after input()?

A simple input-output program takes user data, processes it, and shows a result. For example, a program can ask for a name and display a welcome message. This makes programs dynamic and user-friendly.

What is the purpose of a simple input-output program?
