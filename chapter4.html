Chapter 4: Operators in Python

Arithmetic operators are used to perform mathematical calculations in Python. They allow us to add (+), subtract (-), multiply (*), divide (/), find remainder (%), calculate powers (**), and perform floor division (//). These operators are important when building programs that work with numbers.

Which operator is used for multiplication in Python?

Logical operators are used to combine multiple conditions. The three main logical operators are and, or, and not. They return either True or False and are mainly used inside conditional statements to control program flow.

Assignment operators are used to assign and update values in variables. The basic operator is =. Python also provides shorthand operators like +=, -=, *=, and /=. These make code shorter and help modify values efficiently.
