Chapter 6: Loops

Loops are used to repeat a block of code multiple times. Instead of writing the same code again and again, loops help automate repetition. They are very useful when working with numbers, lists, and repeated tasks.

Why are loops used in programming?

A for loop is used when we know how many times we want to repeat something. It is commonly used with ranges and lists. The loop runs for each value in the sequence until it finishes.

When is a for loop commonly used?

A while loop runs as long as a condition is true. It checks the condition before each repetition. If the condition becomes false, the loop stops. It is useful when the number of repetitions is not fixed.

When does a while loop stop?

The break statement stops a loop immediately. The continue statement skips the current iteration and moves to the next one. The pass statement does nothing and is used as a placeholder in code.
