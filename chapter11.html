Chapter 11: Functions

A function is a block of code that performs a specific task. It helps organize programs into smaller and reusable parts. Instead of writing the same code many times, we create a function and call it whenever needed.

Why do we use functions in programming?

Functions can take inputs called parameters. These parameters allow a function to work with different values. A function can also return a value using the return keyword. The returned value can be stored in a variable.

What does the return keyword do?

There are different types of functions. Some functions take parameters. Some return values. Some do both. Python also has built-in functions like print() and len().

Which is a built-in Python function?

Example of a function: def greet(name): return "Hello " + name This function takes a parameter called name and returns a greeting message.
