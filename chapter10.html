Chapter 10: Dictionaries

A dictionary stores data in key-value pairs. Each key is unique and is used to access its value. Dictionaries are written using curly brackets {}. They are useful when you want to connect related data together.

How is data stored inside a dictionary?

You access dictionary values using their keys. To update a value, assign a new value to its key. If the key does not exist, Python creates a new key-value pair.

How do you update a value in a dictionary?

Common dictionary methods include keys(), values(), and items(). keys() returns all keys. values() returns all values. items() returns both keys and values together.

What does items() return?

You can loop through a dictionary using a for loop. You can loop through keys, values, or both using items(). This helps you work with each key-value pair easily.
