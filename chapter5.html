Chapter 5: Conditional Statements

Conditional statements allow a program to make decisions. The if statement checks a condition. If the condition is True, the code inside the block runs. If it is False, the program skips that block. This helps control how the program behaves.

Which keyword is used to start a condition in Python?

The if else statement gives two possible paths. If the condition is True, one block of code runs. If the condition is False, the code inside the else block runs. This ensures that one of the two actions always happens.

When does the else block run?

The elif statement means "else if". It allows you to check multiple conditions. Python checks each condition in order. When one condition is True, its block runs, and the remaining conditions are skipped.
