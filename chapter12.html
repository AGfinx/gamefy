Chapter 12: Modules and Libraries

A module is a file that contains Python code such as functions and variables. A library is a collection of many modules. Instead of writing everything from the beginning, we can import modules to use ready-made features.

Why do we use modules in Python?

The math module provides mathematical functions. It helps us calculate square roots, powers, and use constants like pi. We must import the module before using it.

Which module is used for mathematical operations?

The random module helps generate random numbers. It can choose a number within a range or select a random item from a list. This is useful in games and simulations.

Which module generates random numbers?

To use a module, we write import module_name at the top of the program. After importing, we use dot notation, like math.sqrt() or random.randint(), to access its functions.
