Chapter 8: Lists

A list is used to store multiple values in one variable. Lists are created using square brackets []. They can store numbers, strings, or mixed data. Lists are ordered and changeable.

How do we create a list in Python?

We access list elements using indexing. Indexing starts from 0. Negative indexing starts from -1 and accesses elements from the end.

What will be the output?

nums = [10, 20, 30]
print(nums[1])

Lists have useful methods like append(), remove(), pop(), insert(), and sort(). These methods help us add, delete, or arrange items in a list.

What does this code do?

fruits = ["apple", "banana"]
fruits.append("mango")

We can loop through a list using a for loop. The loop runs once for each element. This helps us print or work with every item easily.

What will this code print?

numbers = [1, 2, 3]
for n in numbers:
    print(n)
