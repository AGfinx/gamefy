Chapter 2: Variables and Data Types

A variable is used to store data in a program. It works like a container that holds information. In Python, you create a variable using the = symbol to assign a value.

What is a variable in Python?

Python does not require you to declare a data type. You simply assign a value directly. Example: age = 18. Here, age is the variable name and 18 is the stored value.

In the statement age = 18, what is "age"?

Python has rules for naming variables. A name must start with a letter or underscore. It cannot start with a number and is case-sensitive.

Data types define the kind of value stored in a variable. Common types include int (whole numbers), float (decimals), str (text), and bool (True or False).
