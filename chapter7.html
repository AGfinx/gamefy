Chapter 7: Strings

A string is used to store text in Python. It is a sequence of characters written inside single quotes (' ') or double quotes (" "). Everything inside the quotes becomes a string value.

How do we create a string in Python?

Indexing helps us access characters inside a string. Positive indexing starts from 0. Negative indexing starts from -1 and moves backward from the end of the string.

What does negative indexing do?

The first character of a string has index 0. We use square brackets with an index number to access a character. Example: name[0] gives the first letter.
